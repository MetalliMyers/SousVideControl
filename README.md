# SousVideControl
This is a vide-coded garbage javascript web app that uses Google Chrome web bluetooth to connect to my first gen Anova Sous Vide. I created this with claude based on this repo: https://github.com/Aldaviva/SousVide

Claude pulled the bluetooth commands from that repo to extrapolate it into a single page HTML app.

## Setup
1) enable bluetooth in Google Chrome: chrome://flags/#enable-web-bluetooth
2) pair your pc to the Anova via bluetooth
3) Click "connect" on the page
